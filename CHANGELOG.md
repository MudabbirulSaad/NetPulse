# Changelog

All notable changes to NetPulse are recorded here. The project follows Semantic Versioning.

## [1.0.0] - 2026-08-16

### Added

- WPF dashboard with accessible text, icon, and colour health presentation.
- Configurable HTTP and explicit-resolver DNS targets with independent ICMP signals.
- Cancellable per-target scheduling, manual checks, and overlap prevention.
- Rolling latency statistics, 30-sample sparkline, and 100-result target history.
- Atomic local JSON persistence, corruption recovery, and three removable first-run targets.
- Daily sanitized Serilog files with 14-day retention.
- Add, edit, test, enable, disable, and confirmed-delete target workflows.
- Framework-dependent x64 publish and WiX MSI with explicit runtime dependencies.
- 104 deterministic tests, Windows CI artifacts, deployment scripts, and package inspection.
- User, architecture, privacy, troubleshooting, and assessment evidence documentation.
